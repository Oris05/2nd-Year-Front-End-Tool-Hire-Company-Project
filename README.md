Construction Tool Hire Website
Final project for the Front End module (Second Year)
This project is a front‑end web application focused on CSS layout, responsive design, and JavaScript functionality. The goal was to build an interactive construction tool hire website where users can browse tools, view details, and interact with a simple, clean interface.

Project Overview
Home Page
  Introduces the tool hire service
  Highlights featured tools and deals
  Provides clear navigation to all main sections
  Built with responsive CSS (Flexbox/Grid)

Tool Catalogue
  Displays available construction tools
  Includes descriptions, pricing, and hire duration options
  Uses JavaScript for interactive elements (view details, add to hire list)

Hire List (Cart)
  Shows selected tools
  Allows removing items
  Calculates total hire cost

Contact / Information Pages
  Basic company information
  Front‑end contact form layout
  Styled using CSS
  
Technologies Used
  HTML
  CSS (layout, styling, responsive design)
  JavaScript (DOM manipulation, interactive features)

Purpose of the Project
This project demonstrates front‑end development skills learned throughout the module, including layout design, styling, responsive behaviour, and JavaScript functionality. It serves as the final assignment for the Front End module in second year.
